# CodeAlpha Image Gallery
Responsive HTML/CSS/JavaScript image gallery for CodeAlpha Task 1.

## Features
- Responsive masonry-style layout
- Nature, City and Space categories
- Hover effects
- Lightbox view
- Previous/next navigation
- Keyboard support: Esc, ←, →

## Run
Open `index.html` in a browser. Internet access is required for the demo images because they are loaded from Unsplash.
